# 医院无接触式手势辅助交互系统

基于 BX71 / Zynq-7010 的板端手势交互原型。USB 摄像头采图，ARM Linux 使用 OpenCV DNN 运行手掌检测与手部关键点模型，通过几何规则判断静态手势，PL 端 AXI GPIO 控制指示灯与蜂鸣器。

摄像头采集和识别均在板上运行。使用满足板卡电压、电流及接口要求的电源模块供电；电脑仅用于可选的串口调试。不需要 HDMI 显示模块。本原型实现本地声光提示，未接入护士站或医院网络。

## 手势功能

| 手势 | 命令 | 输出 |
|---|---|---|
| 握拳 | 1 | 红灯与蜂鸣器；约 3 秒后蜂鸣器关闭，红灯保持 |
| 伸出食指 | 2 | 黄灯，蜂鸣器关闭 |
| V 手势 | 3 | 绿灯，蜂鸣器关闭 |
| 张掌 | 0 | 灯与蜂鸣器全部关闭 |

连续两次得到相同有效结果后才执行；相同状态不重复触发。无效识别清空候选计数，但不清除已经执行的灯光状态。蜂鸣器的 3 秒等待期间循环暂停，不处理新的取消手势。

## 实测与验证范围

团队反馈：四类手势联动及开机运行已测试成功，从摆出手势到声光反馈开始约 **5–6 秒**。该数值是端到端响应时间，包含连续确认等开销，不是单次模型推理耗时，也不包含后续 3 秒蜂鸣时间。尚未提供正式准确率、测试次数或分场景统计。

此提交包按团队上传的实际源码及串口读取的配置整理，运行逻辑未改动。整理时进行了 C 源码语法检查和 shell 语法检查，未在整理环境重新完成 ARM 链接、Vivado 综合实现或板端测试。

## 文件目录

- `hardware/`：原始 Vivado 工程、Block Design、IP 配置、XDC 和顶层 wrapper。
- `software/capture/bx71_capture.c`：V4L2 采集程序。
- `software/bx71_gesture_photo/`：四类手势识别、CMake 与原始构建脚本。
- `runtime/bx71_gesture_start.sh`：板端实际控制脚本。
- `runtime/inittab.fragment`：实际自动启动配置的一行，不能替换完整 `/etc/inittab`。
- `docs/BUILD_AND_DEPLOY.md`：环境、编译和板端文件清单。
- `docs/SOURCE_NOTES.md`：来源、依赖与已知限制。

**本包是源码归档，不是可直接烧录的系统镜像。** 未包含 ONNX 模型、OpenCV ARM 库、Linux 镜像及可供 FPGA Manager 加载的 `bx71_led_buzzer.bin`。复现需要准备这些依赖；现有正常工作的板卡无需为了上传仓库而重新烧录。
